# Thoughtful Page

한페이지 노트(VOICE BOOK)를 만들어줘.

철학은

"생각을 한 장의 페이지로 남긴다."

사용자가 말하면 브라우저 음성인식을 이용하여

실시간으로 노트에 기록되는 웹서비스이다.

초기 버전은

- React

- TypeScript

- Tailwind

- localStorage

- Web Speech API

를 사용한다.

감성적인 노트 디자인으로 만들어주고

모바일과 PC 모두 지원한다.

Landing Page

Note Editor

Saved Notes

3개의 화면만 먼저 만들어줘.

코드는 확장하기 쉽게 구성해줘.
